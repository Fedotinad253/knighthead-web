# KnightHead — веб-версия

Боссраш по славянской мифологии в браузере: таверна-избушка, карта миров, камень на распутье,
Лихо Одноглазое (три фазы) и Чучело-заглушка вместо остальных боссов. Без движка и без зависимостей:
чистый JavaScript и Canvas 2D.

**Играть:** https://fedotinad253.github.io/knighthead-web/

## Управление

WASD — бег (на карте — бег избушки), мышь — прицел, ЛКМ/ПКМ — лёгкая/тяжёлая атака,
Shift + атака — карта, Пробел — рывок, V — парирование розовых атак, E — действие, Esc — назад, F1 — подсказка.

## Запуск у себя

```
node server/server.js
```
и открыть http://localhost:7777. Сейчас игра одиночная и считается прямо в браузере; прогресс — в localStorage.
Для проверки: `?boss=0&difficulty=1&godmode&debugwin` (сразу в бой, без урона, босс сам теряет здоровье).

## Устройство

- `shared/` — данные (оружие, боссы, сложности), сцены и логика боя (`shared/sim`: сессия, Лихо, Чучело).
- `client/` — рисование (камера под 55°, персонажи из деталей), свой богатырь, интерфейс.
- `server/` — раздача страницы и сетевой кооп по WebSocket (пока выключен в игре; `node server/selftest.js`
  прогоняет бой двумя ботами по сети).
